# Carbon Domain System

A sophisticated dark interface design system optimized for domain marketplace and business directory platforms, featuring high contrast elements and strategic color coding for different states and actions.

## Color Palette

Primary Colors:
- Background: #1a1a1a — Main dark surface color
- Primary Red: #ff4444 — Critical actions, warnings, unavailable items
- Success Green: #00cc66 — Available items, positive actions
- Primary Blue: #4488ff — Premium items, primary CTAs

Neutral Colors:
- Surface Dark: #2a2a2a — Card backgrounds, elevated surfaces
- Text Primary: #ffffff — Main text, headings
- Text Secondary: #cccccc — Secondary text, labels
- Text Muted: #888888 — Disabled text, placeholders
- Border: #333333 — Subtle borders and dividers
- Border Light: #444444 — More prominent borders

Accent/State Colors:
- Success: #00cc66 — Available domains, success states
- Warning: #ffaa00 — Caution states, pending items
- Error: #ff4444 — Unavailable, error states
- Info: #4488ff — Premium items, information states

## Typography

Font Families:
- Primary: System font stack (-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif)
- Interface: Consistent sans-serif throughout

Type Scale:
- Main Title: 32px, 600 weight, 1.2 line-height
- Section Header: 18px, 500 weight, 1.4 line-height
- Body Text: 14px, 400 weight, 1.5 line-height
- Small Text: 12px, 400 weight, 1.4 line-height
- Labels: 13px, 500 weight, 1.3 line-height

Hierarchy Rules:
- Domain names use larger, bold text for prominence
- Status indicators use colored text with consistent sizing
- Prices use blue accent color to draw attention
- Secondary actions use muted text colors

## Spacing System

Base Unit: 8px
Scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64

Common Patterns:
- Component padding: 12px vertical, 16px horizontal
- Card spacing: 16px internal padding
- Section spacing: 24px between major sections
- Button padding: 8px vertical, 16px horizontal
- List item spacing: 12px between items

## Component Styles

### Buttons
Primary (Red):
- Background: #ff4444
- Text: #ffffff
- Padding: 8px 16px
- Border radius: 6px
- Font weight: 500
- Hover: Slight opacity reduction

Secondary (Green):
- Background: #00cc66
- Text: #ffffff
- Same dimensions as primary
- Distinct color coding for different actions

Tertiary/Ghost:
- Background: transparent
- Border: 1px solid #333333
- Text: #cccccc
- Hover: Border color lightens

### Cards/List Items
- Background: #2a2a2a (slightly lighter than main background)
- Border: 1px solid #333333
- Border radius: 8px
- Padding: 16px
- Hover state: Subtle highlight or border color change

### Status Indicators
- Green dot: Available/positive status
- Red dot: Unavailable/negative status
- Blue text: Premium/special designation
- Consistent 6px circular indicators

### Input Fields
- Background: #2a2a2a
- Border: 1px solid #333333
- Border radius: 6px
- Padding: 12px 16px
- Focus: Blue border (#4488ff)
- Text: #ffffff

## Layout Principles

- Max content width: ~1200px with centered alignment
- Three-column layout for domain listings
- Generous whitespace between sections
- Left-aligned text throughout
- Consistent 16px horizontal margins on mobile
- Responsive breakpoints collapse columns on smaller screens

## Visual Effects

- Border Radius: 6-8px for most elements
- Shadows: Minimal, subtle shadows for elevation
- Borders: 1px solid borders in #333333
- Hover Effects: Subtle opacity/color transitions
- No gradients or complex effects
- Clean, flat design aesthetic

## Design Tone

Professional and utilitarian with a focus on data density and quick scanning. The dark theme reduces eye strain during extended browsing sessions while the strategic use of color coding helps users quickly identify domain availability and pricing tiers. The interface prioritizes function over decoration with clean typography and generous whitespace.

## Usage Notes for AI Implementation

- Use consistent color coding: green for available, red for unavailable, blue for premium
- Maintain high contrast ratios for accessibility
- Keep button labels concise and action-oriented
- Use the 8px spacing scale consistently
- Ensure status indicators are immediately recognizable
- Prioritize readability with adequate text sizing
