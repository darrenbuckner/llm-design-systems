# Catalyst Bold System

A striking dark-mode design system built for impact and empowerment messaging. Features dramatic black backgrounds, bold white typography with strong weight contrast, coral-red accent highlights for emphasis, and organic teal flowing decorative elements. Perfect for leadership events, professional summits, and inspirational content that demands attention.

## Color Palette

**Primary Colors:**
- Background Dark: #1F1F1F — Primary background, creates dramatic contrast
- Pure White: #FFFFFF — Primary text, headlines, logos

**Accent Colors:**
- Coral Red: #F0524D — Highlight backgrounds for key phrases, CTAs
- Soft Teal: #8FD9C8 — Decorative flowing elements, organic accents
- Bright Cyan: #00A3E0 — Secondary accent, photography highlights

**Supporting Colors:**
- Near Black: #161616 — Deeper dark areas, overlays
- Warm Gray: #2A2A2A — Card backgrounds, subtle separation
- Light Gray: #B0B0B0 — Secondary text, attributions

**State Colors:**
- Success: #8FD9C8 — Matches teal accent
- Warning: #F5A623 — Warm amber
- Error: #F0524D — Matches coral accent

## Typography

**Font Families:**
- Primary: Heavy condensed sans-serif (similar to Impact, Oswald Black, or Anton)
- Secondary: Elegant serif italic for attributions (similar to Playfair Display Italic or Cormorant Garamond Italic)

**Type Scale:**
- Display/Quote: 64-80px, 900 weight, 1.0-1.1 line-height, tight letter-spacing
- Heading 1: 48-56px, 900 weight, 1.1 line-height
- Heading 2: 32-40px, 800 weight, 1.2 line-height
- Body Large: 24px, 700 weight, 1.3 line-height
- Body: 18px, 400 weight, 1.5 line-height
- Caption/Attribution: 20-24px, 400 italic weight, 1.4 line-height (serif)
- Label: 12-14px, 700 weight, 1.2 line-height, uppercase tracking

**Hierarchy Rules:**
- Headlines use extreme weight (900/Black) for maximum impact
- Quote text uses smart quotes with distinctive styling
- Key phrases highlighted with coral background boxes
- Attributions use contrasting serif italic, right-aligned
- All-caps used sparingly for labels and wordmarks

## Spacing System

**Base Unit:** 8px
**Scale:** 8, 16, 24, 32, 48, 64, 80, 120

**Common Patterns:**
- Quote card padding: 48-64px horizontal, 80-120px vertical
- Text block margins: 32-48px between elements
- Highlight box padding: 8px horizontal, 4px vertical
- Logo placement margins: 48-64px from edges
- Section spacing: 80-120px

## Component Styles

### Quote Cards
- Full-bleed dark background (#1F1F1F)
- Large bold white text, left-aligned
- Coral highlight boxes on key phrases
- Serif italic attribution, right-aligned
- Decorative teal flowing element in top-right corner
- High vertical padding for dramatic negative space

### Highlight Boxes
- Background: #F0524D (coral)
- Text: #FFFFFF (white) or inherits current text color
- Padding: 8px horizontal, 4px vertical
- Border radius: 0px (sharp rectangular)
- Used inline within text for emphasis

### Decorative Elements
- Organic flowing curved lines
- Color: #8FD9C8 (soft teal)
- Stroke width: ~40-60px
- Positioned in corners, extending from off-canvas
- Creates visual interest and organic feel against geometric text

### Logo/Wordmark
- Bold condensed uppercase sans-serif
- Pure white on dark backgrounds
- Horizontal rule accent beneath
- Subtitle in smaller weight, spaced tracking

### Photography Treatment
- Full-bleed imagery for hero slides
- Dark overlay for text legibility when needed
- Professional, candid event photography style
- High contrast, well-lit subjects

## Layout Principles

- Full-bleed dark backgrounds for maximum impact
- Left-aligned text blocks with generous right margin
- Asymmetrical balance with decorative elements
- Strong vertical rhythm with large spacing
- Mobile-first: scales down with maintained proportions
- Grid: Flexible single-column for quotes, can expand to 12-column for complex layouts

## Visual Effects

- **Border Radius:** 0px throughout (sharp, bold aesthetic)
- **Shadows:** None on text; subtle on overlays if needed
- **Borders:** Bold horizontal rules for logo accent (4-6px weight)
- **Backgrounds:** Solid darks, no gradients on primary surfaces
- **Texture:** Organic flowing teal accent provides visual texture

## Design Tone

Bold, empowering, and professional with a modern edge. The system balances dramatic high-contrast typography with organic flowing elements to create an aesthetic that feels both powerful and approachable. The coral highlights add urgency and emphasis while the teal accents soften the overall presentation. Perfect for leadership content, professional events, and messaging that aims to inspire action.

## Usage Notes for AI Implementation

1. **Typography is paramount:** Use extremely bold weights (800-900) for headlines. The impact comes from weight contrast, not color variety.

2. **Highlight sparingly:** Coral highlight boxes should emphasize only 2-5 words per quote. Overuse diminishes impact.

3. **Preserve negative space:** Large margins and padding are intentional. Don't compress spacing to fit more content.

4. **Decorative elements are optional:** The teal flowing accent adds visual interest but can be omitted for simpler implementations.

5. **Attribution styling matters:** The serif italic creates important contrast with bold sans-serif headlines.

6. **Sharp corners throughout:** Do not add border-radius to any elements. The sharp aesthetic is intentional.

7. **Limit color palette:** Stick to the 3-color accent system (white text, coral highlights, teal decoration). Adding more colors dilutes the impact.

8. **Quote formatting:** Use smart quotes (" ") and proper em-dashes. Typography details matter in this system.
