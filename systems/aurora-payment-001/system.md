# Aurora Payment System

Clean, modern payment interface design with cyan accent colors and sophisticated dark overlay aesthetics. Features glass-morphism elements and clear payment interaction patterns.

## Color Palette

Primary Colors:
- Primary Cyan: #00E5FF — Main brand accent, buttons, highlights, interactive elements
- Pure White: #FFFFFF — Primary text, icons, high contrast elements

Surface Colors:
- Dark Overlay: rgba(26, 26, 26, 0.85) — Main interface background with transparency
- Glass Surface: rgba(255, 255, 255, 0.1) — Subtle glass-like overlays

Accent Colors:
- Secondary Blue: #4A90E2 — Language selector, secondary interactive elements
- Muted Cyan: #66D9EF — Secondary highlights and supporting elements

Text Colors:
- Primary Text: #FFFFFF — Main headings, important information
- Secondary Text: rgba(255, 255, 255, 0.8) — Supporting text, labels

## Typography

Font Families:
- Primary: System UI, -apple-system, sans-serif (clean, highly legible)

Type Scale:
- Display/Amount: 72px, 300 weight, 1.1 line-height
- Heading 1: 48px, 400 weight, 1.2 line-height  
- Heading 2: 32px, 400 weight, 1.3 line-height
- Body: 18px, 400 weight, 1.4 line-height
- Caption: 14px, 400 weight, 1.3 line-height

Hierarchy Rules:
- Large monetary amounts use light weight for elegance
- Instructions use medium weight for clarity
- All text maintains high contrast against dark backgrounds

## Spacing System

Base Unit: 8px
Scale: 8, 16, 24, 32, 48, 64, 96

Common Patterns:
- Interface padding: 32px all sides
- Element spacing: 24px vertical gaps
- Button padding: 16px horizontal, 12px vertical
- Icon spacing: 16px from text

## Component Styles

### Primary Display
- Large monetary amount with light font weight
- High contrast white on dark overlay
- Prominent positioning in upper portion

### Instruction Text
- Medium size, clear hierarchy
- White text for maximum readability
- Positioned below primary amount

### Language Selector
- Compact button with globe icon
- Cyan accent color matching brand
- Upper right positioning
- Icon + text combination

### Action Indicators
- "INSERT" text with directional arrow
- Cyan accent color for visibility
- Positioned to guide user action

### Overlay Container
- Semi-transparent dark background
- Rounded corners (16px border radius)
- Glass-morphism effect with subtle transparency
- Edge-to-edge on mobile, contained on larger screens

## Layout Principles

- Mobile-first, full-screen interface approach
- Central focus on payment amount and instructions
- Logical top-to-bottom information hierarchy
- Generous whitespace for touch interactions
- Edge padding maintains readability

## Visual Effects

- Border Radius: 16px for main containers, 8px for buttons
- Backgrounds: Semi-transparent overlays with blur effects
- Shadows: Subtle elevation with dark overlays
- Transparency: Strategic use for glass-morphism effects
- Icons: Simple, geometric shapes with consistent stroke weight

## Design Tone

Modern, trustworthy, and technologically sophisticated. The interface emphasizes clarity and confidence in financial transactions through high contrast, generous spacing, and premium glass-morphism effects. The cyan accent color adds a fresh, digital-forward personality while maintaining professional credibility.

## Usage Notes for AI Implementation

- Always maintain high contrast ratios for accessibility
- Use glass-morphism effects sparingly for premium feel
- Cyan accents should be used for primary actions and brand elements
- Ensure touch targets are minimum 44px for mobile usability
- Layer transparency effects carefully to maintain text readability
