# Tech Platform Hero

Enterprise-grade technical sophistication through its deep teal color palette and serif typography, while maintaining approachability through bright accent colors and playful isometric illustrations. The design balances developer-friendly brand personality with infrastructure authority.

## Color Palette

**Primary Colors:**
- Primary Accent: #00ED64 — Core brand color, used for primary actions, key branding, accent elements, and primary interactive components
- Secondary Accent: #FF9900 — Secondary brand color for partnership branding, used in logo treatments and select accents

**Background Colors:**
- Primary Background: #0A2E3C — Deep teal-blue, main canvas color providing sophisticated tech aesthetic
- Surface Dark: #154455 — Slightly lighter teal for elevated surfaces and layered elements
- Decorative Dark Green: #1A4D3E — Used for organic background shapes and depth layers

**Accent & State Colors:**
- Cyan Accent: #00D4FF — Used for secondary illustrations, data visualization elements
- Success/Active: #00ED64 — Inherits from primary accent for positive states

**Text Colors:**
- Text Primary: #FFFFFF — All headline and body text
- Text on Accent: #0A2E3C — Dark text on bright accent buttons for maximum contrast

**Neutral Colors:**
- Illustration Light: #F5F5F5 — Off-white used in isometric illustrations
- Pure Black: #000000 — Used for illustration outlines and depth definition

## Typography

**Font Families:**
- Primary: Serif typeface (similar to Freight Text or Chronicle Display) — Used for all display text
- Secondary: Sans-serif (similar to Akkurat or Inter) — Used for UI elements and smaller text

**Type Scale:**
- Display/Hero: ~72-80px, Regular (400), 1.1 line-height — Primary headline
- Subheading: ~64-72px, Regular (400), 1.2 line-height — Secondary messaging
- Button Text: ~20-24px, Medium (500), 1.0 line-height
- Logo Text: ~36-40px, Regular (400), 1.0 line-height — Brand wordmarks

**Hierarchy Rules:**
- Headlines use elegant serif typeface to convey enterprise credibility
- Generous letter-spacing on display text (~0.01em)
- Punctuation (periods, commas) included in headlines for complete sentence structure
- Lower-case styling can be used for brand names to create modern, approachable feel

## Spacing System

**Base Unit:** 8px
**Scale:** 8, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Logo lockup spacing: 32px between partner logos (with vertical divider)
- Headline to subheadline: 24-32px vertical spacing
- Subheadline to CTA button: 64-80px vertical spacing
- Section padding: 64-96px from edges
- Illustration breathing room: 96-128px from text elements

## Component Styles

### Buttons
- **Primary CTA Button:**
  - Background: #00ED64 (primary accent)
  - Text: #0A2E3C (dark teal for contrast)
  - Padding: 20px horizontal, 16px vertical
  - Border-radius: 8px
  - Font-size: 22px
  - Font-weight: Medium (500)
  - No border, flat design
  - Hover state: Likely slightly darker shade (#00D957) or subtle shadow

### Logo Lockup
- **Partner Logo Treatment:**
  - Two logos separated by 1px vertical white line divider
  - Height: ~40-48px per logo
  - Spacing: 32px between logos and divider
  - Alignment: Center-aligned vertically
  - Primary brand logo includes icon + wordmark in accent color
  - Partner logo includes wordmark + signature element in contrasting colors

### Illustrations
- **Isometric Technical Illustrations:**
  - Style: 3D isometric perspective with flat color fills
  - Colors: #00ED64 (primary elements), #00D4FF (secondary elements), #F5F5F5 (light surfaces)
  - Outline: 2-3px black strokes for definition
  - Shadows: None, relies on color blocking for depth
  - Composition: Stacked and arranged at angles for dimensional effect
  - Subject matter: Technical/infrastructure elements (databases, servers, architecture)

### Decorative Elements
- **Organic Background Shapes:**
  - Large curved/flowing shapes in #1A4D3E (dark green)
  - Smooth bezier curves creating natural, flowing movement
  - Positioned behind main content to add depth without competing
  - Semi-transparent or layered to create atmospheric depth

## Layout Principles

- Max content width: ~1200-1400px (estimated from composition)
- Grid structure: Asymmetric layout with 60/40 text-to-illustration split
- Left-aligned text content with generous left padding (~80-120px from edge)
- Illustration anchored to right side of canvas
- Vertical rhythm based on 8px grid system
- Hero content positioned in upper-left quadrant
- Decorative elements extend beyond safe content area to edges

## Visual Effects

**Border Radius:**
- 8px on interactive components (buttons), minimal rounding elsewhere

**Shadows:**
- None visible; design relies on flat color and layering for depth

**Borders:**
- 1px white vertical line as logo divider
- 2-3px black outlines on illustrations

**Backgrounds:**
- Primary: Solid color (#0A2E3C)
- Layered organic shapes in darker accent (#1A4D3E)

## Design Tone

This system projects enterprise-grade technical sophistication through its deep teal color palette and serif typography, while maintaining approachability through bright accent colors and playful isometric illustrations. The design balances developer-friendly brand personality with infrastructure authority, using clean geometry, generous whitespace, and a limited color palette to communicate reliability and scalability. The overall aesthetic is modern, confident, and accessible—technical without being intimidating.

## Usage Notes for AI Implementation

**Color Discipline:**
- Reserve #00ED64 (primary accent) exclusively for CTAs, brand elements, and key focus points—never use as large fills
- Maintain dark backgrounds (#0A2E3C) as primary canvas to ensure accent colors have maximum pop
- Ensure text on accent buttons uses #0A2E3C for WCAG AAA contrast compliance

**Typography Application:**
- Use serif fonts only for headlines and display text; never for body copy or UI labels
- Maintain generous line-height (1.1-1.2) on large headlines for elegance and readability
- Keep headlines concise—this system works best with short, punchy messaging

**Illustration Style:**
- Isometric illustrations should be geometric and precise, not organic or hand-drawn
- Use 2-3px black outlines to define all illustration edges
- Limit illustration colors to primary accent (#00ED64), cyan (#00D4FF), and off-white (#F5F5F5)
- Illustrations should occupy 30-40% of layout, never dominating the composition

**Layout Approach:**
- Text should always lead; illustrations support but never overshadow messaging
- Maintain asymmetric layouts with content weighted to left 60% of canvas
- Use decorative organic shapes sparingly—only as atmospheric background elements
- Keep interactive elements (CTAs) in high-visibility positions with surrounding negative space
