# Meadow Workbook System

A warm, approachable design system built for educational and wellness content. Combines clean typography with soft blue accents to create a friendly, non-intimidating learning environment. The aesthetic balances professionalism with warmth, making complex topics feel accessible and personal.

## Color Palette

**Primary Colors:**
- Primary Dark: #1A1A1A — Main headings, emphasis text, logo elements
- Primary Accent: #6CB4D4 — Links, highlights, decorative elements, call-to-action backgrounds

**Neutral Colors:**
- Background Primary: #FFFFFF — Main page background, content areas
- Background Secondary: #F0F7FA — Callout boxes, example sections, highlighted content
- Text Primary: #1A1A1A — Headlines, section titles, bold text
- Text Secondary: #444444 — Body copy, paragraphs
- Text Tertiary: #666666 — Captions, footer text, meta information
- Borders: #E8E8E8 — Dividers, form lines, subtle separators

**Accent/State Colors:**
- Link Blue: #6CB4D4 — Interactive links, clickable elements
- Link Hover: #5A9FBD — Hover state for links
- Decorative Wave: #6CB4D4 — Illustrative wave shapes, visual flourishes
- Input Lines: #1A1A1A — Form field underlines when active

## Typography

**Font Families:**
- Primary Headings: Playfair Display or similar serif — Used for main titles with elegant, approachable feel
- Secondary Headings: System sans-serif (likely -apple-system, BlinkMacSystemFont, "Segoe UI") — Section headings
- Body: System sans-serif — Clean, readable body text
- Monospace: Courier New or similar — Instructional labels, form prompts ("Your Plan:")

**Type Scale:**
- Display/Logo: 32-40px, 700 weight, tight letter-spacing, mixed case styling
- Heading 1: 28-32px, 700 weight, 1.2 line-height, serif
- Heading 2: 22-26px, 700 weight, 1.3 line-height, sans-serif
- Heading 3: 18-20px, 700 weight, 1.4 line-height, sans-serif
- Body: 16-17px, 400 weight, 1.6-1.7 line-height
- Caption/Small: 13-14px, 400 weight, 1.5 line-height
- Label/Mono: 14-15px, 400 weight, monospace

**Hierarchy Rules:**
- Main titles use serif font for warmth and approachability
- Section headings use bold sans-serif for clarity
- Body text maintains generous line-height for readability
- Bold inline text (#1A1A1A, 600-700 weight) for key concepts
- Monospace text for instructional prompts and form labels
- Italics used sparingly for parenthetical notes and gentle emphasis

## Spacing System

**Base Unit:** 8px
**Scale:** 4, 8, 16, 24, 32, 48, 64, 80

**Common Patterns:**
- Component padding: 24px (callout boxes), 32px (content sections)
- Section spacing: 48-64px between major sections
- Paragraph spacing: 16-24px between paragraphs
- Line spacing in forms: 40-48px between input lines
- Page margins: 24-32px on mobile, 48-80px on desktop
- Rounded corner containers: 8-12px border-radius

## Component Styles

### Buttons
- Not prominently featured; design relies on links
- Links: #6CB4D4, underlined or plain, 16px
- Hover: Darker shade #5A9FBD, optional underline

### Cards/Callout Boxes
- Background: #F0F7FA (soft blue tint)
- Border: 1px solid #E8E8E8 or none
- Border Radius: 8-12px
- Padding: 24-32px
- Used for examples, highlighted content, key takeaways

### Input Fields/Form Lines
- Style: Bottom border only (underline style)
- Border: 1px solid #1A1A1A
- Spacing: 40-48px between lines
- Label: Monospace, 14px, positioned above
- No background fill, minimal aesthetic

### Content Containers
- Border: 1px solid #1A1A1A with rounded corners
- Border Radius: 12-16px
- Padding: 32-48px
- Used for title cards, major content blocks

### Illustrations
- Style: Simple line art, black outlines
- Fill: Minimal, mostly white with occasional pattern (dots)
- Characters: Friendly, approachable, faceless or simple
- Integration: Paired with decorative wave shapes in accent blue

### Numbered Lists
- Number style: Bold, followed by period
- Spacing: 16-24px between items
- Indent: Hanging indent style

## Layout Principles

- Max content width: 680-720px for optimal reading
- Grid structure: Single column for content, centered
- Responsive behavior: Generous margins collapse on mobile
- Alignment: Left-aligned text, centered decorative elements
- Vertical rhythm: Consistent spacing creates calm, organized feel

## Visual Effects

- **Border Radius:** 8-12px for callouts, 12-16px for major containers
- **Shadows:** None or very subtle; flat design aesthetic
- **Borders:** 1px solid, rounded corners, used sparingly
- **Backgrounds:** White primary, soft blue (#F0F7FA) for highlights
- **Decorative Elements:** Curved wave shapes in accent blue, simple illustrations
- **Dividers:** Horizontal lines (1px solid #1A1A1A) above/below titles

## Design Tone

Warm, supportive, and educational. The design feels like a trusted friend guiding you through complex topics. The soft blue accent color and generous whitespace create a calming, non-overwhelming experience. Typography choices balance authority (serif headings) with accessibility (clean sans-serif body). The overall aesthetic is professional yet personal, structured yet flexible.

## Usage Notes for AI Implementation

When implementing this system, prioritize readability and warmth. Use the soft blue callout boxes to highlight important information, examples, or key takeaways. Reserve bold text for crucial concepts that readers should remember. The monospace font signals "your turn" moments where users should write or reflect. Maintain generous line-height and spacing to prevent content from feeling dense or academic. Illustrations should be simple and friendly, never complex or intimidating. The wave shape element can be used as a section divider or decorative footer element to add visual interest while maintaining the calm, supportive tone.
