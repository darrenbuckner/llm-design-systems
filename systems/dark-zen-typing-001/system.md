# Carbon Flow System

A minimalist dark interface design focused on eliminating distractions while highlighting key information through strategic color accents.

## Color Palette

**Primary Colors:**
- Background: #3A3A3A — Deep charcoal background providing comfortable dark experience
- Surface: #4A4A4A — Subtle elevation for UI elements and buttons
- Text Primary: #FFFFFF — Pure white for maximum contrast and readability

**Accent Colors:**
- Orange Highlight: #F5A623 — Warm amber for achievements, progress, and key metrics
- Green Success: #4CD964 — Vibrant green for positive states and accomplishments
- Text Secondary: #A8A8A8 — Medium gray for supporting information

**Interactive States:**
- Button Inactive: rgba(255,255,255,0.2) — Semi-transparent white overlay
- Button Active: #FFFFFF — Solid white for primary actions
- Indicators: #6A6A6A — Muted gray for pagination dots (inactive)

## Typography

**Font Families:**
- Primary: System font stack (San Francisco on iOS, similar clean sans-serif)
- Display: Custom serif-like font for large numbers and emphasis

**Type Scale:**
- Display Large: 120px+, Regular weight, 1.1 line-height — Hero numbers and key metrics
- Heading 1: 48px, Medium weight, 1.2 line-height — Primary headings
- Heading 2: 32px, Regular weight, 1.3 line-height — Section headers
- Body Large: 20px, Regular weight, 1.4 line-height — Primary content
- Body: 16px, Regular weight, 1.5 line-height — Standard text
- Caption: 14px, Regular weight, 1.4 line-height — Supporting information

**Hierarchy Rules:**
- Use size contrast rather than weight changes for hierarchy
- Maintain consistent line spacing for readability
- Large display numbers use custom serif styling for elegance

## Spacing System

**Base Unit:** 8px
**Scale:** 8, 16, 24, 32, 48, 64, 96px

**Common Patterns:**
- Component padding: 24px vertical, 32px horizontal
- Section spacing: 48px between major sections
- Element spacing: 16px between related elements
- Screen margins: 24px from edges

## Component Styles

### Buttons
- **Primary Button:** White background (#FFFFFF), dark text, 48px height, 24px horizontal padding, fully rounded corners
- **Secondary Button:** Transparent background with white text, minimal styling
- **Icon Buttons:** 64px circular containers with 20px icons, semi-transparent gray background

### Cards/Containers
- Background: Same as main background (#3A3A3A)
- No visible borders or shadows
- Content organized through spacing and typography hierarchy
- Minimal visual separation

### Navigation Elements
- **Pagination Dots:** 8px circles, inactive gray (#6A6A6A), active white (#FFFFFF)
- **Close Button:** X icon in circular 64px container
- **Action Icons:** Gift and settings icons in matching circular containers

## Layout Principles

- **Centered Layout:** All content center-aligned for focus
- **Generous Whitespace:** Ample spacing around all elements
- **Full-Screen Experience:** Content takes full viewport with consistent margins
- **Vertical Flow:** Elements stacked vertically with clear hierarchy

## Visual Effects

- **Border Radius:** Full rounded corners for buttons and icon containers
- **Shadows:** No drop shadows used — relies on color and spacing for depth
- **Borders:** No visible borders — separation through whitespace
- **Transparency:** Strategic use of semi-transparent overlays for inactive states

## Design Tone

Clean, focused, and distraction-free aesthetic that emphasizes content over interface chrome. The design creates a zen-like environment for concentration while using vibrant accent colors to celebrate achievements and progress.

## Usage Notes for AI Implementation

This system works best for productivity, meditation, or focus-oriented applications. Use the dark background as the foundation, apply generous whitespace liberally, and reserve orange/green accents exclusively for highlighting achievements, progress, or positive states. Maintain the minimalist approach by avoiding unnecessary visual elements.
