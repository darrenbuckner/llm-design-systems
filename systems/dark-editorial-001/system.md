# Inkwell Editorial

A sophisticated dark-mode editorial design that balances elegant serif italic headlines with clean sans-serif body text. The system creates a premium publication aesthetic through high contrast, refined typography mixing, and strategic accent colors. Perfect for content-forward platforms, newsletters, and digital publications.

## Color Palette

**Primary Colors:**
- Background: #000000 — Primary surface, deep black
- Text Primary: #FFFFFF — High contrast white for headlines and primary text
- Accent Teal: #7DD3C8 — Call-to-action buttons, interactive elements
- Accent Coral: #E07A5F — Secondary accent, author highlights, emphasis

**Neutral Colors:**
- Surface: #000000 — Main background
- Text Primary: #FFFFFF — Headlines, navigation, key content
- Text Secondary: #9CA3AF — Supporting text, metadata, descriptions
- Text Muted: #6B7280 — Tertiary information, timestamps
- Borders: #374151 — Subtle dividers and separations

**Semantic Colors:**
- Interactive: #7DD3C8 — Buttons, links
- Highlight: #E07A5F — Callouts, author names, important notes
- Success: #34D399 — Confirmations, positive states
- Warning: #FBBF24 — Caution states
- Error: #EF4444 — Error states

## Typography

**Font Families:**
- Display/Headlines: Libre Baskerville (or similar elegant serif), italic style
- Body: Inter (or similar clean geometric sans-serif)
- UI Elements: Inter

**Type Scale:**
- Display: 48-56px, italic, 400 weight, 1.1 line-height
- Heading 1: 40-48px, italic serif, 400 weight, 1.15 line-height
- Heading 2: 24px, sans-serif, 600 weight, 1.3 line-height
- Body Large: 18px, sans-serif, 400 weight, 1.6 line-height
- Body: 16px, sans-serif, 400 weight, 1.6 line-height
- Caption: 14px, sans-serif, 400 weight, 1.5 line-height
- Small: 12px, sans-serif, 500 weight, 1.4 line-height

**Typography Rules:**
- Headlines use elegant serif italic for editorial sophistication
- Body text uses clean sans-serif for optimal readability on dark backgrounds
- Mixed typography creates visual hierarchy and editorial character
- Generous line-height for comfortable reading
- High contrast (white on black) for accessibility

## Spacing System

**Base Unit:** 8px
**Scale:** 4, 8, 12, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Component padding: 12-16px horizontal, 10-14px vertical
- Section spacing: 48-64px vertical margins
- Card padding: 24px
- Button padding: 12px 24px
- Navigation spacing: 24-32px between items
- Content max-width: ~720px for readability

## Layout Principles

- Max content width: 720px for article content
- Full-width header navigation
- Generous vertical spacing between sections
- Left-aligned content (flush left)
- Clear visual hierarchy through size and weight contrast
- Mobile-first responsive design

## Visual Effects

**Border Radius:**
- Buttons: 6px
- Cards: 8px
- Avatars: 50% (circular)
- Input fields: 6px

**Shadows:**
- Minimal shadow usage on dark backgrounds
- Subtle elevation on hover states only
- Focus: outline-based rather than shadow

**Borders:**
- Accent borders: 3px solid for emphasis
- Dividers: 1px solid #374151
- Used sparingly to maintain clean aesthetic

**Backgrounds:**
- Solid black primary background
- No gradients in core design
- Transparency used for overlays

## Design Tone

This design system embodies refined editorial sophistication with a contemporary edge. The combination of elegant serif italics with clean sans-serif creates a sense of premium content while maintaining excellent readability. The dark background with teal and coral accents feels modern and tech-forward while retaining classical publishing sensibilities. The overall tone is intellectual, trustworthy, and premium.

## Usage Notes for AI Implementation

1. **Typography Mixing:** Always pair serif italic headlines with sans-serif body text—never use all-serif or all-sans-serif
2. **Color Restraint:** Use coral accent sparingly for emphasis; teal for primary actions only
3. **Spacing Generosity:** Err on the side of more whitespace; cramped layouts break the editorial feel
4. **Contrast Priority:** Maintain high contrast ratios given the dark background
5. **Callout Pattern:** Use left-border accent cards for important asides or notes
6. **Author Attribution:** Circle avatars with name to the right; include role/badge icons when relevant
7. **Navigation Simplicity:** Keep nav minimal—icons left, logo center, CTA right
8. **Mobile Adaptation:** Stack elements vertically, maintain generous touch targets (44px minimum)
