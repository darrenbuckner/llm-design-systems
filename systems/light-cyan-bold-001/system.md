# Cyan Bold System

A high-impact editorial design system featuring vibrant cyan backgrounds, extra bold serif headlines, and strategic use of high-contrast color blocking. Built for attention-grabbing promotional content and bold brand statements.

## Color Palette

**Primary Colors:**
- Cyan Primary: #00BFFF — Vibrant background color, brand signature
- Black: #000000 — Headlines, primary text, high contrast elements
- Orange Accent: #FF4500 — Call-to-action buttons, emphasis elements

**Neutral Colors:**
- White: #FFFFFF — Secondary text, contrast elements
- Dark Gray: #1A1A1A — Body text on light backgrounds
- Light Gray: #F5F5F5 — Alternative background, subtle surfaces

**Text Colors:**
- Primary Text: #000000 — Headlines and emphasis
- Secondary Text: #1A1A1A — Body copy
- Inverse Text: #FFFFFF — Text on colored backgrounds

## Typography

**Font Families:**
- Primary (Headlines): Bold Serif (Playfair Display Extra Bold, Georgia, or similar high-impact serif)
- Secondary (Body): Clean Sans-Serif (Inter, system-ui, or similar)

**Type Scale:**
- Display/Hero: 72-96px, 800-900 weight, 0.95-1.0 line-height
- Heading 1: 48-64px, 800-900 weight, 1.0 line-height
- Heading 2: 36-42px, 700-800 weight, 1.1 line-height
- Body Large: 20-24px, 400-500 weight, 1.5 line-height
- Body: 16-18px, 400 weight, 1.6 line-height
- Small/Caption: 14px, 400 weight, 1.4 line-height

**Hierarchy Rules:**
- Headlines use extra bold serif with tight leading for maximum impact
- Body text uses clean sans-serif for readability
- Price/numeric emphasis uses bold weight with strikethrough for discounts
- All-caps used sparingly for labels and CTAs

## Spacing System

**Base Unit:** 8px
**Scale:** 8, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Button padding: 16px 32px
- Section spacing: 48-64px vertical
- Content padding: 48-64px on desktop, 24-32px on mobile
- Text block spacing: 24-32px between elements
- Tight headline spacing: 0-8px between headline lines

## Component Styles

### Buttons
- **Primary CTA:**
  - Background: #FF4500 (Orange)
  - Text: #FFFFFF (White), uppercase, 14-16px, 700 weight
  - Padding: 16px 32px
  - Border radius: 0px (sharp corners)
  - Border: None
  - Hover: Darken background to #E03E00

- **Secondary Button:**
  - Background: #000000 (Black)
  - Text: #FFFFFF (White)
  - Same padding and structure as primary

### Typography Treatment
- **Strikethrough Price:**
  - Original price with text-decoration: line-through
  - Light gray color (#999999)
  - Positioned before new price
  - Both prices use bold weight

### Logo/Brand Mark
- Simple, clean sans-serif
- Black on light backgrounds
- White on dark backgrounds
- Often positioned bottom right with generous spacing

### Labels/Tags
- All-caps text
- White text on orange background
- Padding: 12px 24px
- Sharp corners (0px border radius)

## Layout Principles

- Full-bleed colored backgrounds for maximum impact
- Generous whitespace around text blocks
- Left-aligned text for editorial feel
- Asymmetric compositions
- Single-column focus on mobile
- Logo/branding positioned strategically (often bottom right)
- High contrast between background and text

## Visual Effects

- **Border Radius:** 0px (sharp, editorial corners throughout)
- **Shadows:** None (flat design approach)
- **Borders:** Minimal use, when present: 1-2px solid black
- **Backgrounds:** 
  - Bold solid colors (cyan primary)
  - High saturation for impact
  - No gradients or textures

## Design Tone

Bold, confident, and editorial. This system commands attention through high-contrast color relationships and oversized serif typography. The aesthetic feels premium and journalistic while maintaining accessibility through clear hierarchy and generous spacing. The vibrant cyan creates an unmistakable brand moment, while the sharp geometric shapes and flat design keep the focus on content and message.

## Usage Notes for AI Implementation

When implementing this system, prioritize maximum visual impact through color contrast and typography scale. Use the cyan background liberally for hero sections and key brand moments. The extra bold serif should be reserved for headlines only—never use it for body text. Maintain sharp corners (0px border radius) throughout for consistency with the editorial aesthetic. The orange accent color is specifically for calls-to-action and should be used sparingly for maximum effectiveness. Ensure sufficient whitespace around text blocks to let the bold typography breathe. Price treatments with strikethroughs should always show the discount clearly with the original price in a lighter gray.
