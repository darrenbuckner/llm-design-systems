# Midnight Collective

A high-impact dark theme design system built for showcasing statistics, highlights, and community metrics. Features a pure black canvas with stark white typography and two distinct accent colors: electric violet for data and metrics, vibrant red-orange for interactive elements and decorative shapes. The system emphasizes dramatic scale contrasts and editorial clarity.

## Color Palette

**Primary Colors:**
- Background: #000000 — Pure black, primary canvas
- Text Primary: #FFFFFF — Pure white, headlines and body
- Accent Violet: #A855F7 — Electric violet, statistics and numbers
- Accent Orange: #E84715 — Vibrant red-orange, decorative blobs and icons

**Secondary Colors:**
- Violet Dark: #9333EA — Deeper violet for hover/active states
- Violet Light: #C084FC — Lighter violet for subtle accents
- Gold Accent: #C8A97A — Warm gold for special highlights and diagrams

**Neutral Colors:**
- Surface: #000000 — Pure black
- Text Primary: #FFFFFF — Pure white
- Text Secondary: #A1A1A1 — Mid gray for captions and metadata
- Borders: #333333 — Dark gray, subtle divider lines
- Divider Line: #404040 — Slightly lighter for horizontal rules

**State Colors:**
- Interactive: #E84715 — Orange for active states
- Hover: #FF5722 — Brighter orange on hover
- Focus Ring: #A855F7 — Violet for focus indicators

## Typography

**Font Families:**
- Primary: Inter, system-ui, -apple-system, sans-serif
- Alternative: SF Pro Display, Helvetica Neue

**Type Scale:**
- Display/Stats: 120-180px, 300-400 weight, 0.9 line-height — Massive statistics
- Heading 1: 48px, 400 weight, 1.1 line-height
- Heading 2: 32px, 400 weight, 1.2 line-height
- Heading 3: 24px, 400 weight, 1.3 line-height
- Body Large: 20px, 400 weight, 1.5 line-height
- Body: 16px, 400 weight, 1.6 line-height
- Caption: 14px, 400 weight, 1.4 line-height — Italicized for image captions
- Label: 12px, 500 weight, 1.2 line-height, uppercase, letter-spacing 0.05em

**Hierarchy Rules:**
- Statistics use massive display sizes (100px+) in violet accent color
- Supporting text below stats uses white at body size
- Section headings are large but lighter weight than stats
- Body text maintains comfortable reading width
- Captions use italic styling for editorial feel

## Spacing System

**Base Unit:** 8px
**Scale:** 4, 8, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Component padding: 24px internal padding
- Section spacing: 64-96px between major sections
- List item spacing: 24px between items with divider lines
- Container padding: 48-64px horizontal on mobile
- Stat block vertical rhythm: 32px between stat and label

## Component Styles

### Statistics Display
- Number size: 100-180px
- Number weight: 300-400 (light to regular)
- Number color: #A855F7 violet
- Label below: 16-20px white
- Optional image thumbnail: 120px width, 8px border-radius, right-aligned
- Divider below: 1px #404040 line

### List Items (Highlights)
- Text: 18-20px white
- Padding: 20px vertical
- Divider: 1px #404040 bottom border
- Icon: Starburst/rosette shape in #E84715 orange, 24px
- Right-aligned icon with left-aligned text

### Navigation Arrow Button
- Shape: Pill/stadium, 48px height
- Border: 1px white stroke
- Background: Transparent
- Arrow: Thin line arrow →
- Hover: White fill with black arrow

### Decorative Blob
- Shape: Organic cloud/blob form
- Color: #E84715 solid orange
- Usage: Partial visibility, cropped at edges
- Scale: Large, 40-60% of viewport width

### Tags/Labels
- Background: #FFFBF5 (warm off-white)
- Text: #E84715 orange
- Padding: 8px 16px
- Border-radius: 4px
- Font: 11px uppercase, 500 weight, 0.1em letter-spacing

### Image Cards
- Border-radius: 8px
- Can have duotone orange overlay
- Caption below: italic, centered, #A1A1A1

## Layout Principles

- Max content width: 1200px
- Mobile-first with generous padding (48px+)
- Single column dominant on mobile
- Stats paired with small images on desktop
- Asymmetric blob positioning creates visual interest
- Strong vertical rhythm with horizontal dividers

## Visual Effects

- **Border Radius:** 8px for images, 24px for pills, organic curves for blobs
- **Shadows:** None — flat design aesthetic
- **Borders:** 1px lines only, #404040 for dividers, white for buttons
- **Backgrounds:** Pure black with colored blob accents bleeding off-screen
- **Image Treatment:** Can use duotone orange overlay for photos

## Design Tone

This system projects bold editorial confidence with a creative community focus. The stark black-and-white foundation provides maximum contrast, while the violet statistics command attention and the orange accents add warmth and energy. The organic blob shapes soften the minimal grid, suggesting creativity and human connection. Overall aesthetic is modern, artistic, and data-forward — perfect for showcasing community achievements and cultural highlights.

## Usage Notes for AI Implementation

1. **Statistics are the hero** — Use massive violet numbers as primary visual anchors
2. **Maintain stark contrast** — Pure black and white only, no grays for main content
3. **Blobs add personality** — Include partial orange shapes at section edges
4. **Dividers create rhythm** — Use thin lines between repeating list items
5. **Light weight typography** — Keep font weights at 300-400 for elegance
6. **Starburst icons** — Use rosette/seal shapes for list bullets in orange
7. **Pill buttons for navigation** — Thin white-bordered stadium shapes
8. **Editorial captions** — Italicize image descriptions
9. **Generous whitespace** — Let content breathe with large vertical spacing
10. **Two accent colors only** — Violet for data, orange for decoration/interaction
