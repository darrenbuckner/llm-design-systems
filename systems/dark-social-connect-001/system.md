# Social Connect Dark

Modern, playful, and community-focused dark theme with strong gaming/tech culture influence. The design balances professionalism with personality through vibrant illustrations, bold typography, and expressive design while maintaining accessibility and clear hierarchy.

## Color Palette

**Primary Colors:**
- Primary Blue: #5865F2 — Primary brand color, used for primary CTAs, focus states, and key interactive elements
- Primary Blue Dark: #4752C4 — Darker variant for hover states on primary buttons

**Background Colors:**
- App Background: #1E1F22 — Main application background
- Surface Dark: #2B2D31 — Elevated surfaces, modals, cards
- Surface Darker: #313338 — Input fields, secondary surfaces
- True Black: #000000 — Used in status bar area and deep backgrounds

**Text Colors:**
- Text Primary: #FFFFFF — Primary headings and emphasized text
- Text Secondary: #B5BAC1 — Body text, descriptions, secondary information
- Text Tertiary: #80848E — Placeholder text, labels, de-emphasized content

**Accent Colors:**
- Link Blue: #00AFF4 — Hyperlinks, inline links
- Success Green: #3BA55D — Success states, positive actions
- Cyan Accent: #00D9FF — Glowing effects, highlights in illustrations

**Illustration Colors:**
- Illustration Blue: #5865F2 — Primary shapes in illustrations
- Illustration Purple: #A855F7 — Secondary shapes, variety
- Illustration Green: #3ECF8E — Accent elements in illustrations
- Illustration Pink: #EB459E — Highlight elements
- Illustration Yellow: #FEE75C — Small accent details
- Illustration Coral: #F26E6E — Warm accent elements

**Border/Divider:**
- Border Subtle: #3F4147 — Subtle borders, dividers

## Typography

**Font Families:**
- Primary: Custom sans-serif (similar to Whitney/SF Pro) — Clean, geometric, highly legible

**Type Scale:**
- Heading Large: 28px, 800 weight (Black/Heavy), 32px line-height
- Heading Primary: 24px, 600 weight (Semibold), 28px line-height
- Body Large: 16px, 400 weight (Regular), 22px line-height — Descriptive text
- Body: 14px, 400 weight (Regular), 20px line-height — Standard body text
- Label: 14px, 500 weight (Medium), 18px line-height — Form labels
- Small/Caption: 12px, 400 weight (Regular), 16px line-height

**Hierarchy Rules:**
- Headings use white (#FFFFFF) for maximum contrast
- Body text uses secondary gray (#B5BAC1)
- Labels use tertiary gray (#80848E)
- Display headings use extra-bold weights (800) with generous letter-spacing
- Links use bright blue (#00AFF4) with no underline by default

## Spacing System

**Base Unit:** 4px
**Scale:** 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80

**Common Patterns:**
- Modal top padding: 80px (to illustration)
- Section vertical spacing: 24px between elements
- Text block spacing: 16px between heading and body
- Component padding: 16px horizontal, 12px vertical for inputs
- Button padding: 16px vertical, 24px horizontal
- Edge margins: 27px horizontal screen edges

## Layout Principles

- Max content width: Full width on mobile (screen width minus 27px margins)
- Vertical rhythm: Consistent 24px spacing between major sections
- Responsive behavior: Full-screen modals, stacked layout
- Alignment: Center-aligned for illustrations and headings, left-aligned for body text
- Touch targets: Minimum 44×44px for all interactive elements
- Bottom spacing: 32px minimum from bottom edge to button

## Design Tone

Modern, playful, and community-focused with strong gaming/tech culture influence. The dark theme creates an immersive environment while vibrant illustrations and accent colors add energy and approachability. Heavy use of rounded shapes, bold typography, and expressive illustrations convey a young, dynamic, and social atmosphere. The design balances professionalism (clear hierarchy, accessible text) with personality (colorful characters, glowing effects, enthusiastic language).

## Usage Notes for AI Implementation

- Dark backgrounds are fundamental—never use light mode colors
- Primary blue (#5865F2) is the brand anchor; use it confidently for primary actions but avoid overuse
- Illustrations should be playful and character-driven with the established color palette
- Maintain generous whitespace—don't crowd elements
- All interactive elements must meet 44×44px minimum for mobile touch
- Text hierarchy is critical: white for emphasis, gray for supporting content
- Links use bright blue (#00AFF4), distinct from the primary brand blue
- Buttons should feel substantial with adequate padding and full-width treatment on mobile
- When creating promotional content, lean into bold display typography and eye-catching 3D/glow effects while maintaining readability
