# Coral Financial System

A clean, minimal financial interface system featuring warm coral accents, generous white space, and high readability optimized for trust and accessibility.

## Color Palette

Primary Colors:
- Primary (Coral): #E53E3E — Brand accent, CTAs, focus states
- Text Primary: #000000 — Main headings, primary text
- Text Secondary: #718096 — Labels, secondary text, links

Surface Colors:
- Background: #F7FAFC — Page background, subtle contrast
- Surface: #FFFFFF — Cards, form containers, elevated content
- Input Background: #F7FAFC — Form field backgrounds

State Colors:
- Focus/Hover: #E53E3E — Interactive state indicators
- Border Default: #E2E8F0 — Subtle borders and dividers

## Typography

Font Families:
- Primary: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif

Type Scale:
- Heading 1: 48px, 600 weight, 1.2 line-height
- Heading 2: 24px, 400 weight, 1.3 line-height  
- Body: 16px, 400 weight, 1.5 line-height
- Label: 14px, 500 weight, 1.4 line-height
- Small/Caption: 14px, 400 weight, 1.4 line-height

Hierarchy Rules:
- Main headings use bold weight and larger sizes
- Labels use medium weight for emphasis
- Body text maintains comfortable reading weight
- Generous line-height for readability

## Spacing System

Base Unit: 8px
Scale: 8, 16, 24, 32, 48, 64, 80px

Common Patterns:
- Form field padding: 16px
- Card padding: 24px
- Section spacing: 48px vertical
- Button padding: 16px horizontal, 12px vertical
- Container max-width: ~600px
- Generous whitespace between major sections

## Component Styles

### Buttons
- Primary: Black (#000000) background, white text, rounded corners (8px)
- Padding: 16px horizontal, 16px vertical
- Font: 16px, medium weight
- Full-width on mobile, auto-width on desktop
- Smooth hover transitions

### Input Fields
- Background: Light gray (#F7FAFC)
- Border: None (borderless design)
- Padding: 16px
- Border radius: 8px
- Font size: 16px
- Label positioning: Above field with small margin

### Cards/Containers
- Background: White (#FFFFFF)
- Border radius: 16px (generous rounding)
- Padding: 32-48px
- Subtle shadow or border for definition
- Centered layout with max-width constraints

### Links
- Color: Medium gray (#718096)
- No underline by default
- Hover state with underline
- Comfortable spacing between multiple links

## Layout Principles

- Max content width: ~600px for forms, centered
- Generous padding: 24-32px on containers
- Vertical rhythm: Consistent 16-24px spacing between elements
- Mobile-first responsive approach
- Centered alignment for main content
- Ample whitespace for breathing room

## Visual Effects

- Border Radius: 8px for buttons/inputs, 16px for cards
- Shadows: Subtle, minimal shadow usage
- Borders: Minimal, prefer borderless inputs
- Backgrounds: Clean whites and light grays
- Focus states: Coral accent color outlining

## Design Tone

Clean, trustworthy, and approachable. The system emphasizes clarity and ease of use with generous spacing, high contrast text, and minimal visual noise. The coral accent adds warmth while maintaining professional credibility essential for financial applications.

## Usage Notes for AI Implementation

- Prioritize readability with high contrast text
- Use generous spacing to reduce cognitive load
- Apply coral accent sparingly for maximum impact
- Maintain consistent 8px spacing grid
- Ensure form fields are touch-friendly (44px+ tap targets)
- Keep layouts simple and uncluttered
