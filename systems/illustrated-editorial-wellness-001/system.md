# Vitality Editorial System

A distinctive illustrated editorial design system that combines sophisticated 3D-style iconography with clean typographic layouts. The aesthetic balances scientific credibility with approachable warmth through its muted teal-coral palette and playful illustrated borders. Ideal for health, wellness, science communication, and educational content platforms.

## Color Palette

**Primary Colors:**
- Sage Teal: #6B9B9B — Primary brand color, used in illustrations and UI elements
- Deep Teal: #1E3A3A — Headlines, icons, and strong contrast elements
- Muted Coral: #E8A87C — Secondary accent, warmth and human elements

**Neutral Colors:**
- Paper White: #F5F5F5 — Primary background, content areas
- Soft Gray: #E0E0E0 — Subtle borders, dividers
- Charcoal: #2D2D2D — Body text, primary typography
- Slate: #5A5A5A — Secondary text, captions

**Accent Colors:**
- Soft Mint: #D4E5E5 — Highlight backgrounds, subtle accents
- Golden Yellow: #FFDE59 — Emphasis highlights, key phrases
- Peach: #F5C4A1 — Warm illustration elements
- Steel Blue: #4A7C7C — Darker teal variations

**Illustration Palette:**
- Light Teal: #8BB8B8 — 3D illustration fills
- Shadow Teal: #4A7878 — Illustration shadows and depth
- Coral Light: #F5D4BC — Skin tones, warm elements
- Brain Pink: #D4A5A5 — Organic illustration elements

## Typography

**Font Families:**
- Primary (Headlines): Serif typeface (Georgia, Playfair Display, or similar editorial serif)
- Secondary (Body): System sans-serif (Inter, -apple-system, or similar)
- Accent (Quotes): Same serif as headlines with increased size

**Type Scale:**
- Display Quote: 48-56px, 400 weight, 1.2 line-height — Featured quote text
- Heading 1: 36px, 600 weight, 1.3 line-height
- Heading 2: 28px, 600 weight, 1.35 line-height
- Heading 3: 22px, 500 weight, 1.4 line-height
- Body: 16-18px, 400 weight, 1.6 line-height
- Caption: 14px, 400 weight, 1.5 line-height
- Small/Label: 12px, 500 weight, 1.4 line-height

**Hierarchy Rules:**
- Large quotes use serif typography with generous letter-spacing
- Key phrases receive highlight treatment (light yellow/mint background)
- Curly quote marks ("") styled as decorative elements in deep teal
- Headlines maintain strong contrast against illustrated backgrounds

## Spacing System

**Base Unit:** 8px

**Scale:** 4, 8, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Card padding: 32-48px
- Section spacing: 64-96px
- Inline highlight padding: 4px 8px
- Quote mark offset: 16px from text
- Illustration border width: 80-120px frame around content

**Content Container:**
- Max content width: 720px for reading
- Illustration frame: Extends 80-120px beyond content on all sides
- Central content area: Clean white with generous whitespace

## Component Styles

### Quote Cards
```
Structure:
- Outer frame: Illustrated border (80-120px)
- Inner content: White background (#F5F5F5)
- Rounded corners: 16-24px on device frame
- Shadow: Subtle drop shadow on device mockup

Quote styling:
- Opening quote mark: 48px, #1E3A3A, positioned top-left
- Text: 48-56px serif, #2D2D2D
- Highlighted phrases: #FFDE59 or #D4E5E5 background
- Attribution: 14px, #5A5A5A, bottom-right
```

### Illustrated Borders
```
Composition:
- 3D-style icons arranged in frame pattern
- Mix of health/science imagery (hearts, brains, DNA, charts)
- Fitness elements (weights, treadmills, gym equipment)
- Tech elements (chips, data visualizations)
- Depth created through layering and shadows
- Color harmony within teal-coral-yellow palette
```

### Highlight Pills
```
Background: #FFDE59 (golden) or #D4E5E5 (mint)
Padding: 4px 8px
Border-radius: 4px
Display: inline
Purpose: Emphasize key phrases within quotes
```

### Device Frame
```
Border: 1px solid #E0E0E0
Border-radius: 24px (outer), 16px (inner screen)
Background: #F5F5F5
Shadow: 0 4px 24px rgba(0,0,0,0.1)
Notch: Subtle top-center indicator
```

## Layout Principles

**Content Structure:**
- Central focal point with illustrated frame
- Clean whitespace in content area
- Illustrations provide visual interest without competing with text
- Quote text is the clear hero element

**Visual Balance:**
- Illustrated elements distributed evenly around frame
- Heavier elements (treadmill, brain) balanced with lighter ones
- Color distributed to avoid hot spots
- Yellow accent line provides grounding/baseline

**Responsive Behavior:**
- Illustrated border scales proportionally
- Quote text size reduces on mobile (36-40px)
- Border width reduces to 60-80px on smaller screens
- Maintains aspect ratio on resize

## Visual Effects

**Border Radius:**
- Device frames: 24px outer, 16px inner
- Highlight pills: 4px
- Icon containers: 8-12px
- Buttons: 8px

**Shadows:**
- Device frame: 0 4px 24px rgba(0,0,0,0.1)
- Illustration depth: Multiple layers with 2-4px offsets
- Subtle: 0 2px 8px rgba(0,0,0,0.05) for cards

**Illustration Style:**
- 3D isometric-style iconography
- Soft shadows for depth
- Flat color fills with gradient overlays
- Consistent 30-45° viewing angle
- Rounded forms, friendly aesthetic

**Textures & Patterns:**
- Subtle paper texture on background (#F5F5F5)
- Dotted/stippled effects on some illustrations
- Grid patterns in data visualization elements
- Organic shapes for biological elements

## Design Tone

This system projects **intellectual warmth** — the combination of scientific iconography with soft, approachable colors creates trust while remaining accessible. The editorial serif typography adds gravitas and credibility, while the playful 3D illustrations prevent the design from feeling clinical or cold. The highlighted phrases create clear takeaways, making complex information scannable and memorable. Overall: friendly expertise, like a knowledgeable friend explaining health science.

## Usage Notes for AI Implementation

**When to use this system:**
- Health and wellness content platforms
- Science communication and education
- Podcast/video quote cards for social media
- Newsletter hero sections
- Editorial long-form content
- Research summaries and insights

**Key implementation details:**
- Always maintain clean central content area
- Use illustrated borders sparingly (hero moments only)
- Highlight only 1-2 key phrases per quote
- Ensure quote marks are decorative but not overwhelming
- Keep illustrations thematically relevant to content

**Accent color strategy:**
- Yellow highlights for actionable insights
- Mint highlights for definitions or key terms
- Coral accents for human/emotional elements
- Deep teal for scientific/technical elements

**Typography pairing:**
- Serif for quotes and major headlines only
- Sans-serif for all supporting text
- Never mix serif in body paragraphs

**Illustration guidelines:**
- Maintain consistent 3D style across all icons
- Use the defined color palette strictly
- Balance organic (brain, heart, DNA) with mechanical (equipment, charts)
- Ensure illustrations support, not compete with, text content
