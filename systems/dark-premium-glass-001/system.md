# Premium Glass Rewards

Premium, dark, modern design system with sophisticated glass morphism and financial credibility. Translucent panels with subtle blur for depth and sophistication, creating a luxurious yet trustworthy aesthetic for financial applications.

## Color Palette

**Primary Colors:**
- Deep Navy/Dark Blue: #0A1628 — Primary background, main UI surfaces representing trust, stability, financial sophistication
- Sky Blue/Light Blue: #B3D4E8 — Primary CTAs, active states, highlights representing clarity, approachability, rewards
- Soft Sage/Muted Green: #8EA99E — Success states, "Active" indicators, positive actions representing growth, stability, financial health

**Secondary Colors:**
- Warm White/Off-White: #FFFFFF — Primary text, headers, important information with high contrast against dark backgrounds
- Cool Gray Spectrum:
  - Light: #E8ECEF — Light gray for secondary text on dark
  - Mid: #8B95A3 — Muted gray for tertiary information
  - Dark: #4A5564 — For subtle dividers and borders

**Glass Morphism Colors:**
- Translucent Panels:
  - Background: rgba(26, 42, 63, 0.7) — Dark blue with 70% opacity
  - Alternative: rgba(15, 25, 40, 0.8) — Deeper with 80% opacity
  - Border: rgba(255, 255, 255, 0.1) — Subtle white border
  - Backdrop Filter: blur(20px) saturate(180%)

**Accent Colors:**
- Muted Gold/Amber: #D4A574 — Warm, sophisticated gold for premium features, special moments, tier indicators
- Soft Orange/Peach: #FFB380 — Warmth in imagery, evening/ambient contexts

## Typography

**Font Families:**
- Primary: Modern Sans-Serif (SF Pro, Inter, or custom geometric sans) — Clean, highly readable, slightly wider letterforms for all UI text, headers, body copy
- Monospace (Optional): SF Mono, IBM Plex Mono — Financial figures, precise data display with fixed-width, clear numerals

**Type Scale:**
- H1 (Large Display): 40-48px, Regular-Medium (400-500), 1.1 line-height — Hero headlines, primary screens
- H2 (Section Header): 28-34px, Regular-Medium (400-500), 1.2 line-height — Card titles, major sections
- H3 (Subsection): 22-26px, Medium (500), 1.3 line-height — Component headers
- H4 (Component Title): 18-20px, Medium-Semibold (500-600), 1.4 line-height — List items, card headers
- Body Large: 17-18px, Regular (400), 1.5 line-height — Important descriptions, value propositions
- Body: 15-16px, Regular (400), 1.5 line-height — Standard text, descriptions
- Body Small: 13-14px, Regular-Medium (400-500), 1.4 line-height — Secondary info, metadata, labels
- Caption: 11-12px, Medium (500), 1.3 line-height — Fine print, subtle labels
- Financial Display: 24-32px, Regular (400), 1.2 line-height — Dollar amounts, points, key metrics (consider monospace for precision)

**Typography Guidelines:**
- Hierarchy: Subtle size differences with weight and color for distinction
- Spacing: Generous letter spacing (0.01-0.02em) for elegance
- Alignment: Left-aligned for most text, centered for modals
- Color: White for primary, light gray for secondary, mid gray for tertiary
- Financial Data: Clear, precise, easily scannable at a glance

## Spacing System

**Base Unit:** 4px
**Scale:** 2, 4, 8, 12, 16, 24, 32, 40, 48, 64

**Spacing Applications:**
- Screen Padding: 20-24px horizontal (consistent edge spacing)
- Vertical Rhythm: 16-24px between related elements
- Section Spacing: 40-48px between major sections
- Card Padding: 20-24px internal padding
- Component Spacing: 12-16px between list items
- Micro Spacing: 4-8px for tightly coupled elements

## Layout Principles

**Grid System:**
- Columns: Single column for mobile (primary), multi-column for tablet+
- Margins: 20-24px screen edges
- Gutters: 16-20px between cards/elements
- Max Width: 428px for mobile, 768px for tablet, 1024px desktop

**Layout Patterns:**

**Hero/Content Over Image:**
- Full-bleed background image (high-quality architecture/lifestyle)
- Dark overlay gradient for text readability
- Content positioned in safe zones (top third, avoiding faces)
- Translucent UI elements float above

**Card Layouts:**
- Translucent glass cards with blur
- Rounded corners (16-24px)
- Stacked vertically with 16-20px gaps
- Full width minus screen margins

**Navigation:**
- Top navigation: Segmented pill control
- Bottom navigation: Icon + label, clean and minimal
- Both use translucent backgrounds with blur

**Information Display:**
- Two-column data display (label left, value right)
- Clean dividers between rows
- Consistent internal padding
- Clear visual hierarchy

## Visual Effects

**Border Radius:**
- Buttons: 12-16px (generous rounding)
- Cards: 20-24px
- Pills: 100px (full pill)
- Inputs: 12-16px

**Shadows:**
- Card shadow: 0 8px 32px rgba(0, 0, 0, 0.3)
- Button shadow: 0 4px 12px rgba(179, 212, 232, 0.3)
- Subtle, never harsh

**Glass Morphism:**
- Backdrop filter: blur(20px) saturate(180%)
- Browser fallback: Increase opacity to 0.95 for browsers without backdrop-filter support

**Backgrounds:**
- High-quality background photography
- Dark gradient overlays (radial or top-to-bottom, 50-60% opacity)
- Organic flowing shapes for atmospheric depth

## Design Tone

This design system prioritizes premium aesthetics with financial trustworthiness. The dark UI creates sophistication while the glass morphism adds contemporary polish. Every element should feel intentional and refined, balancing aspiration with accessibility and building trust through refined aesthetics.

## Usage Notes for AI Implementation

**Glass Morphism CSS:**
```css
.glass-card {
  background: rgba(26, 42, 63, 0.7);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 24px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
}

/* Fallback for browsers without backdrop-filter */
@supports not (backdrop-filter: blur(20px)) {
  .glass-card {
    background: rgba(26, 42, 63, 0.95);
  }
}
```

**Key Implementation Points:**
- Use high-quality background photography with proper dark overlays
- Apply glass morphism with proper blur to cards
- Maintain generous spacing and padding throughout
- Ensure high contrast for text readability (white text on dark glass)
- Use translucent panels for depth, max 2-3 layers
- Keep financial data clear and scannable
- Test on actual mobile devices
- Respect safe areas (notches, home indicators)
- Never sacrifice readability for aesthetics
