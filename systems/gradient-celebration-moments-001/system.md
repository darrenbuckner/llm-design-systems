# Celebration Moments

Bold, celebratory design system that screams confidence through supersized typography, saturated gradients, and premium product photography. Designed for instant emotional impact—treating everyday delivery as a special occasion worth celebrating.

## Color Palette

**Primary Colors:**
- Primary Red: #DD1A1A — Core brand color, used for CTAs, badges, and primary messaging
- Vibrant Coral-Red: #F24E4E — Secondary brand accent for gradient transitions and emphasis

**Background Colors:**
- Hot Pink/Magenta: #E84B8A — Upper hero background, energetic and attention-grabbing
- Coral-Orange: #F36856 — Mid-section gradient transition
- Soft Pink-White: #F7E5E8 — Lower section background, softer and more approachable
- Pure White: #FFFFFF — Content areas, card backgrounds

**Accent Colors:**
- Yellow-Gold: #FFD700 — Accent elements
- Teal-Blue: #4A9B9B — Product accent
- Lavender: #C8A8D8 — Product accent

**Text Colors:**
- Text Primary (on light): #DD1A1A — Headlines, emphasis text
- Text Secondary (on light): #FFFFFF — Body copy on colored backgrounds
- Text Light: #FFFFFF — All text on red/pink backgrounds

## Typography

**Font Families:**
- Primary Display: Bold geometric sans-serif, similar to Montserrat Bold/Black or Gotham Bold — high impact, rounded terminals
- Body/Support: Medium-weight sans-serif, likely same family as display

**Type Scale:**
- Hero/Display: ~80-100px, Black (900), line-height 0.9-1.0 — Ultra-bold, condensed spacing
- Subheading: ~40-50px, Bold (700), line-height 1.1
- Percentage/Promo: ~120-140px, Black (900), line-height 0.85 — Massive numerals
- Body Copy: ~16-18px, Regular (400), line-height 1.3
- Fine Print: ~12-14px, Regular (400), line-height 1.2

**Hierarchy Rules:**
- Headlines use all caps or sentence case with extreme weight contrast
- Display type is tightly kerned for maximum impact
- Supporting copy uses white on red for high contrast
- Quotes use quotation marks as design elements, not typographic quotes

## Spacing System

**Base Unit:** 8px
**Scale:** 8, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Promo badge padding: 16px vertical, 32px horizontal
- Edge margins: 24-32px on mobile-sized layouts
- Inter-element spacing: 24-32px between major sections
- Tight text spacing: 8-16px between related text lines
- Hero image breathing room: 48-64px padding around product hero

## Component Styles

### Promo Badge
- **Style:** Rounded horizontal pill shape
- **Background:** #DD1A1A (solid red)
- **Border Radius:** 40-50px (fully rounded ends)
- **Padding:** 16px vertical, 32-48px horizontal
- **Text:** White, bold, mixed sizes (large percentage + smaller terms)
- **Shadow:** None or subtle 0 2px 8px rgba(0,0,0,0.1)

### Product Photography
- **Treatment:** Clean, high-contrast photography on gradient backgrounds
- **Style:** Floating/levitating effect with subtle shadows
- **Composition:** Arranged in dynamic, diagonal cascading layout
- **Shadow:** Soft contact shadows, 0 8px 24px rgba(0,0,0,0.15)

### Hero Section
- **Background:** Gradient from magenta (#E84B8A) to coral (#F36856) to soft pink (#F7E5E8)
- **Direction:** Vertical gradient, top to bottom
- **Image Treatment:** Products float above background with natural shadows
- **Text Placement:** Bottom third, centered or left-aligned

### Typography Lockup
- **Style:** Bold statement headlines with tight leading
- **Color:** Primary red (#DD1A1A) on light backgrounds
- **Emphasis:** Uses quotation marks as graphic elements, not semantic punctuation
- **Alignment:** Center-aligned for impact

## Layout Principles

- Max Content Width: ~375-414px (mobile-first vertical mailer/card format)
- Grid Structure: Single column, centered content flow
- Content Flow: Hero image → Promo badge → Headline → (implied CTA below fold)
- Alignment: Center-aligned for promotional elements, creating symmetry and focus
- Vertical Rhythm: Tight spacing at top transitions to more breathing room at bottom

## Visual Effects

**Border Radius:**
- Promo badges: 40-50px (pill shape)
- Cards/containers: 0-8px (minimal, likely 0 for this design)

**Shadows:**
- Product photography: 0 8px 24px rgba(0,0,0,0.15) — soft drop shadow
- Promo badge: 0 4px 12px rgba(221,26,26,0.25) — subtle red glow (optional)
- Elevation: Single layer, no complex depth system

**Backgrounds:**
- Gradient: Linear gradient, vertical direction, 3-stop gradient (magenta → coral → soft pink)
- Photography: High saturation, vivid colors, professional product shots
- No patterns or textures, relies on color and photography

**Special Effects:**
- Floating/suspension illusion for products
- Dramatic perspective and depth through photography
- High contrast between subjects and backgrounds

## Design Tone

Bold, celebratory, and unabashedly indulgent. This system screams confidence through supersized typography, saturated gradients, and premium product photography. It's designed for instant emotional impact—treating everyday delivery as a special occasion worth celebrating. The aesthetic balances aspirational luxury with accessible friendliness through warm gradient transitions and playful composition.

## Usage Notes for AI Implementation

- **Gradient is essential:** The pink-to-coral gradient creates the energetic foundation; don't replace with solid colors
- **Photography is hero:** Product imagery should be high-quality, well-lit, and composed dynamically—not static grid layouts
- **Type should dominate:** Headlines need to be LARGE and BOLD, taking up significant real estate
- **Red is for action:** Use the primary red (#DD1A1A) sparingly but decisively for CTAs, promos, and key messaging
- **Contrast matters:** Always ensure white text on red/pink backgrounds and red text on white/light backgrounds
- **Mobile-first:** This system is optimized for vertical, thumb-friendly formats
- **Celebrate the moment:** Design language should feel special, premium, and worth sharing—not utilitarian or purely functional
