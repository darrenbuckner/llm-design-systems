# Obsidian Publisher System

A dark, high-contrast design system for publishing platforms with bold red accent colors and clean typography hierarchy.

## Color Palette

Primary Colors:
- Primary: #000000 — Main background and active states
- Accent: #E53E3E — CTAs, highlights, and interactive elements
- White: #FFFFFF — Primary text and form backgrounds

Neutral Colors:
- Surface/Background: #000000 — Main page background
- Light Surface: #F7F7F7 — Input backgrounds and light sections
- Text Primary: #FFFFFF — Main text on dark backgrounds
- Text Secondary: #000000 — Text on light backgrounds
- Borders: #F7F7F7 — Subtle element separation

State Colors:
- Interactive: #E53E3E — Buttons, links, active states
- Inactive: #F7F7F7 — Disabled or secondary elements

## Typography

Font Families:
- Primary: System serif stack (likely Georgia, Times New Roman)
- Secondary: System sans-serif stack

Type Scale:
- Heading 1: 48px, normal, 1.2
- Heading 2: 36px, normal, 1.3
- Body: 16px, normal, 1.6
- Button Text: 14px, bold/semibold, 1.0
- Navigation: 18px, normal, 1.4

Hierarchy Rules:
- Large serif headings for emphasis and branding
- Clean sans-serif for navigation and UI elements
- High contrast white text on dark backgrounds
- Bold button text for clear CTAs

## Spacing System

Base Unit: 8px
Scale: 8, 16, 24, 32, 48, 64, 96

Common Patterns:
- Component padding: 16px-24px
- Section spacing: 64px-96px vertical
- Button padding: 16px 32px
- Input padding: 16px

## Component Styles

### Buttons
- Primary: Red background (#E53E3E), white text, bold weight
- Rectangular with minimal border radius (0-2px)
- Generous padding: 16px 32px
- All caps or bold text treatment
- No shadows, flat design approach

### Input Fields
- Light background (#F7F7F7) on dark sections
- Rectangular with minimal border radius
- Generous padding: 16px
- Placeholder text in medium gray
- Clean, minimal styling

### Pagination
- Number buttons with light backgrounds (#F7F7F7)
- Active state: solid black background, white text
- Rectangular buttons, consistent sizing
- "NEXT PAGE" text in all caps
- Clean, functional layout

### Navigation
- White text on dark background
- Clean typography hierarchy
- Minimal, text-based approach
- Clear vertical spacing between items

## Layout Principles

- Max content width: ~800px for reading content
- Full-width dark sections for contrast
- Centered content alignment
- Generous white space usage
- Clear content hierarchy with spacing

## Visual Effects

- Border Radius: 0-2px (minimal, rectangular approach)
- Shadows: None (flat design aesthetic)
- Borders: Minimal use, mainly for form elements
- Backgrounds: High contrast (pure black/white)

## Design Tone

Bold, authoritative, and reader-focused. The system emphasizes content readability with high contrast and clean typography. The dark theme with red accents creates a sophisticated publishing atmosphere that feels professional and literary.

## Usage Notes for AI Implementation

This system works best for content-heavy applications like publishing platforms, literary sites, or editorial interfaces. The high contrast ensures excellent readability, while the red accent provides clear visual hierarchy for interactive elements. Use generous spacing and maintain the serif/sans-serif contrast for optimal content presentation.
