# Neon Spectrum

A bold, modern design system featuring a dark background with vibrant purple-to-violet gradients. Clean sans-serif typography, minimalist components, and strategic use of neon accents create a high-energy, tech-forward aesthetic. Perfect for innovative platforms and forward-thinking digital products.

## Color Palette

**Primary Colors:**
- Primary Gradient Start: #7C3AED — Primary action elements, hero backgrounds, bold accents
- Primary Gradient End: #6D28D9 — Secondary gradients, depth variation, dark accents
- Primary Light Accent: #A78BFA — Hover states, highlights, interactive feedback

**Neutral Colors:**
- Background: #0F0E1E — Main page background
- Surface Secondary: #1A1528 — Card backgrounds, elevated surfaces
- Text Primary: #FFFFFF — Primary headings and body text
- Text Secondary: #9CA3AF — Secondary text, descriptions, metadata
- Borders: #2D263A — Subtle dividers, component borders

**State Colors:**
- Success: #10B981 — Positive actions, confirmations
- Warning: #F59E0B — Caution states, alerts
- Error: #EF4444 — Destructive actions, errors
- Info: #3B82F6 — Informational content

## Typography

**Font Families:**
- Primary: Inter or -apple-system, sans-serif
- Secondary: Same as primary (system sans-serif)

**Type Scale:**
- Display: 48px, 700, 1.2 line-height
- Heading 1: 36px, 700, 1.3 line-height
- Heading 2: 28px, 600, 1.3 line-height
- Heading 3: 20px, 600, 1.4 line-height
- Body Large: 16px, 400, 1.6 line-height
- Body: 14px, 400, 1.5 line-height
- Caption: 12px, 500, 1.4 line-height

**Hierarchy Rules:**
- Headers use full white (#FFFFFF) for maximum contrast on dark background
- Body text uses white at 100% opacity for primary content, gray (#9CA3AF) for secondary
- Breadcrumbs and secondary navigation use smaller gray text (12-14px)
- All text is sharp and highly legible against dark backgrounds

## Spacing System

**Base Unit:** 4px
**Scale:** 4, 8, 12, 16, 24, 32, 48, 64

**Common Patterns:**
- Component padding: 16-24px internal padding for cards and sections
- Section spacing: 48-64px between major content blocks
- Grid gaps: 16-24px between grid items
- Margin top on text elements: 8-12px for breathing room

## Component Styles

### Buttons
- Primary: Full purple gradient (#7C3AED to #6D28D9), white text, 8px border-radius, padding 12-16px
- Secondary: Gradient outline style with 1px transparent border, text colored with accent
- Hover: Lighter gradient shade (#A78BFA lightening), slight elevation
- Active: Darker shade, pressed appearance

### Cards
- Background: #1A1528 surface
- Border: 1px #2D263A subtle divider
- Border-radius: 8-12px
- Padding: 20-24px
- Shadows: Subtle elevation shadow (0 4px 16px rgba(124, 58, 237, 0.1))
- Hover: Slight glow effect with gradient accent border

### Input Fields
- Background: #0F0E1E (same as page background) with subtle border
- Border: 1px #2D263A
- Border-radius: 6-8px
- Padding: 12px 16px
- Text color: #FFFFFF
- Focus: Border changes to #7C3AED with subtle glow
- Placeholder: #6B7280 (lighter gray)

### Navigation
- Background: Semi-transparent or dark surface
- Text: White for active, gray for inactive
- Hover: Text becomes lighter gradient color
- Active indicator: Gradient accent or underline using primary gradient

### Badges & Tags
- Background: Subtle gradient overlay or solid accent color with transparency
- Text: White or light
- Border-radius: 16-20px
- Padding: 6-8px 12-16px

## Layout Principles

- Max content width: ~1200px for desktop
- Grid structure: 12-column responsive grid with 16px gutters
- Responsive breakpoints: 320px (mobile), 768px (tablet), 1024px (desktop), 1440px (wide)
- Column spacing: Collapses to 1-2 columns on mobile, expands to full grid on desktop
- Section alignment: Center-aligned content with breathing room
- Asymmetrical layouts with visual card elements offset for dynamism

## Visual Effects

- **Border Radius:** 6px (inputs), 8px (cards), 12px (buttons), 16px (large elements)
- **Shadows:** Subtle elevation system using gradient-tinted shadows (rgba(124, 58, 237, 0.1) to 0.2))
- **Borders:** 1px solid #2D263A for subtle dividers
- **Gradients:** Purple to violet (#7C3AED to #6D28D9) used throughout for primary actions
- **Glows:** Subtle box-shadow glow effect on hover/focus states
- **Background:** Deep dark #0F0E1E with optional subtle gradient overlay

## Design Tone

Modern, energetic, and forward-thinking. This system exudes innovation and boldness through its vibrant purple gradients contrasted against a deep dark background. The clean sans-serif typography maintains sophistication and readability, while the neon accents create visual excitement and draw attention to key interactions. Perfect for tech platforms, creative tools, and products targeting a design-conscious audience.

## Usage Notes for AI Implementation

Use this system for interfaces requiring high visual impact and modern aesthetics. The purple gradient primary color works as a versatile hero element. Distribute accent colors strategically rather than overusing them. Maintain the contrast hierarchy between white and gray text. When implementing gradients, ensure smooth color transitions. Test all interactive states (hover, focus, active) to verify the gradient accents remain visible and accessible. The dark background reduces eye strain for extended use, making it ideal for intensive productivity tools.
