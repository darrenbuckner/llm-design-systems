# Copper Starburst

A bold, retro-inspired dark theme that combines a warm charcoal base with vibrant copper accents. The design features distinctive starburst decorative elements and a developer-focused aesthetic that feels both nostalgic and modern. The chunky geometric logo treatment and expressive typography create a memorable, community-driven feel.

## Color Palette

**Primary Colors:**
- Primary Accent: #E07A3D — Vibrant copper/burnt orange, used for key visual elements, icons, and calls to action
- Secondary Accent: #8B5A3D — Deep terracotta brown, used for decorative elements like starbursts

**Neutral Colors:**
- Background: #2D2A26 — Warm dark charcoal with slight brown undertone
- Text Primary: #BFBAB4 — Warm light gray for main headings and primary content
- Text Secondary: #7A7571 — Muted warm gray for supporting text and metadata
- Text Tertiary: #5A5652 — Darker gray for less prominent elements

**Semantic Colors:**
- Interactive Hover: #F08A4D — Lighter copper for hover states
- Focus Ring: #E07A3D40 — Semi-transparent copper for focus indicators
- Divider: #3D3935 — Subtle warm separator lines

## Typography

**Font Families:**
- Display/Logo: Custom geometric sans-serif (similar to Righteous, Bungee, or custom display face) — lowercase with chunky letterforms
- Primary: System sans-serif stack (Inter, -apple-system, system-ui) — clean and readable
- Monospace: SF Mono, Monaco, Consolas — for any code elements

**Type Scale:**
- Display: 72-96px, 700 weight, 1.0 line-height — for hero titles
- Heading 1: 48-56px, 600 weight, 1.1 line-height — section headers
- Heading 2: 32-40px, 600 weight, 1.2 line-height — subsection headers
- Body Large: 18px, 400 weight, 1.6 line-height — primary content
- Body: 16px, 400 weight, 1.5 line-height — standard text
- Caption: 14px, 400 weight, 1.4 line-height — metadata and supporting info
- Small: 12px, 400 weight, 1.3 line-height — timestamps, counts

**Hierarchy Rules:**
- Display typography uses lowercase letters for a friendly, approachable feel
- Headlines pair large scale with generous letter-spacing
- Body text maintains high contrast against dark background
- Metadata uses muted colors but remains legible

## Spacing System

**Base Unit:** 8px
**Scale:** 4, 8, 12, 16, 24, 32, 48, 64, 96, 128

**Common Patterns:**
- Container padding: 24-48px
- Section spacing: 64-96px vertical
- Element gaps: 16-24px
- Inline spacing: 8-12px
- Card padding: 24-32px

## Component Styles

### Icons/Logos
- Style: Chunky geometric shapes with bold strokes
- Colors: Primary accent (#E07A3D) for key icons
- Size: Large and prominent, often 80-120px
- Treatment: Flat design, no gradients or shadows

### Decorative Elements
- Starburst/Asterisk: Multi-arm radial pattern in secondary accent (#8B5A3D)
- Position: Offset from main content, creates visual interest
- Scale: Large (100-200px), semi-transparent or solid
- Purpose: Adds retro flair and breaks up dark space

### Text Badges/Metadata
- Layout: Inline with separators (dots, pipes)
- Typography: Small caps or standard small text
- Spacing: 8px between elements
- Color: Muted text secondary

### Social Proof Elements
- Emoji reactions: Inline, clustered together
- Counts: Right-aligned, muted color
- Avatars: Small circular, 24-32px

## Layout Principles

- Content Width: Centered, max-width 800-1000px for readability
- Alignment: Center-aligned for hero content, left-aligned for lists
- Visual Balance: Decorative elements offset to create asymmetry
- Hierarchy: Large focal elements draw eye, supporting content subdued
- Grid: Flexible, content-driven rather than rigid columns

## Visual Effects

- **Border Radius:** 8-12px for cards and buttons, 4px for small elements
- **Shadows:** Minimal to none — flat design aesthetic
- **Borders:** Subtle, 1px, using divider color (#3D3935)
- **Backgrounds:** Solid colors, no gradients
- **Decorative:** Starburst elements add texture without complexity

## Design Tone

This system projects a **retro-futuristic, developer-community** aesthetic. The warm copper against charcoal feels inviting and energetic while maintaining the dark theme preferred by developers. The lowercase typography and starburst decorations create a playful, approachable personality that suggests creativity and collaboration. It's bold without being aggressive, nostalgic without feeling dated.

## Usage Notes for AI Implementation

1. **Color Application:** Use the copper accent sparingly for maximum impact — icons, key headings, and CTAs only. Let the warm charcoal background dominate.

2. **Typography Pairing:** The display font should only be used for hero elements. Fall back to clean sans-serif for all body content.

3. **Decorative Elements:** Starbursts work best as background accents, partially visible or cropped at edges. Don't center them — offset creates better visual interest.

4. **Maintaining Warmth:** The slight brown undertone in all colors is key to this system's personality. Avoid pure blacks or cool grays.

5. **Developer Context:** This aesthetic suits tools, resources, and community projects. It communicates "built by developers, for developers" through its choices.

6. **Social Elements:** When showing engagement metrics, cluster emoji reactions and keep counts understated. The focus should be on content, not metrics.

7. **Responsive Approach:** Scale decorative elements down on mobile but don't remove them — they're essential to the personality.
