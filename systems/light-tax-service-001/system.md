# Sage Financial System

A clean, approachable design system for financial services that balances professionalism with friendly accessibility through soft illustrations and confident green branding.

## Color Palette

Primary Colors:
- Primary Green: #2D5B3F — Main brand color for CTAs and key elements
- Primary Green Hover: #4A6B56 — Hover state for interactive elements

Neutral Colors:
- Background: #F8F6F3 — Warm off-white main background
- Surface White: #FFFFFF — Card backgrounds and content areas
- Text Primary: #1A1A1A — Main heading and body text
- Text Secondary: #666666 — Supporting text and descriptions
- Borders/Dividers: #E5E5E5 — Subtle borders and separators

Accent Colors:
- Illustration Accents: #7FB069 — Light green for illustrations
- Illustration Blue: #4A9EE0 — Blue accents in illustrations
- Illustration Yellow: #F4D03F — Yellow highlights in illustrations

## Typography

Font Family:
- Primary: System font stack (likely -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto)

Type Scale:
- Main Heading: 48px, Bold (700), 1.1 line-height
- Section Heading: 20px, Bold (700), 1.3 line-height  
- Body Text: 16px, Regular (400), 1.5 line-height
- Button Text: 16px, Medium (500), 1.2 line-height

Hierarchy Rules:
- Main headlines use larger, bold typography with tight line-height
- Body text maintains readability with generous line-height
- All text uses dark colors for strong contrast on light background

## Spacing System

Base Unit: 8px
Scale: 8, 16, 24, 32, 48, 64, 80px

Common Patterns:
- Component padding: 24px vertical, 32px horizontal
- Section spacing: 80px between major sections
- Grid gaps: 32px between cards
- Button padding: 16px vertical, 48px horizontal

## Component Styles

### Primary Button
- Background: #2D5B3F
- Text: White, Medium weight
- Border Radius: 32px (fully rounded)
- Padding: 16px 48px
- Hover: #4A6B56 background
- Typography: 16px, Medium weight
- Minimum width for balanced proportions

### Navigation
- Back button: Left-aligned with arrow icon
- Close button: Right-aligned X icon
- Clean, minimal styling with subtle hover states

### Illustration Cards
- Clean line art style with flat colors
- Green, blue, and yellow accent palette
- Friendly, approachable character design
- Simple geometric shapes and objects

### Process Steps
- Four-column layout on desktop
- Numbered sequence implied by layout
- Icon + headline + description structure
- Consistent spacing and alignment

## Layout Principles

- Max content width: ~1200px
- Grid structure: 4-column layout for process steps
- Generous whitespace for breathing room
- Center-aligned main content
- Responsive behavior: Stack columns on mobile

## Visual Effects

- Border Radius: 32px for buttons (fully rounded)
- Shadows: Minimal to none, clean flat design
- Borders: Subtle when needed, very light gray
- Backgrounds: Soft, warm off-white primary surface

## Design Tone

Professional yet approachable financial service design that removes intimidation through friendly illustrations and clear information hierarchy. The warm off-white background and confident green branding create trust while maintaining accessibility.

## Usage Notes for AI Implementation

Use the warm off-white background (#F8F6F3) as the primary surface with white content areas. Apply the green primary color sparingly for key actions. Maintain generous whitespace and use the system font stack for optimal cross-platform rendering. Keep illustrations simple and friendly to balance the professional financial context.
