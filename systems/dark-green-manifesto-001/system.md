# Forest Principles Design System

A sophisticated dark green aesthetic built around structured content presentation with cream-colored cards on a rich forest gradient background. This system emphasizes clarity, hierarchy, and intentional spacing for personal or professional frameworks.

## Color Palette

**Primary Colors:**
- Forest Green Primary: #2D5547 — Main background, badges, accent elements
- Forest Green Deep: #1E3A2F — Darker gradient base, emphasis elements
- Forest Green Light: #4A7C66 — Lighter gradient top, hover states

**Surface Colors:**
- Card Background: #F5F3EF — Warm cream for content cards
- Page Background: Linear gradient from #4A7C66 to #2D5547

**Text Colors:**
- Heading Text: #FFFFFF — White for main heading on dark background
- Primary Text: #1A1A1A — Dark gray/black for card headings
- Body Text: #3D3D3D — Medium gray for card body content
- Badge Text: #FFFFFF — White for numbered badges

**Border/Accent:**
- Badge Background: #2D5547 — Matches primary green
- Card Shadow: rgba(0, 0, 0, 0.1) — Subtle elevation

## Typography

**Font Families:**
- Heading: Serif (Georgia, Garamond, or similar elegant serif)
- Body/UI: Sans-serif (system-ui, -apple-system, or Inter)

**Type Scale:**
- Display Heading (H1): 48px, 400 weight, 1.2 line-height
- Card Heading: 20-22px, 700 weight, 1.3 line-height
- Body Text: 16-17px, 400 weight, 1.6 line-height
- Category Label: 15-16px, 400 weight, parenthetical style

**Hierarchy Rules:**
- Main heading uses large serif centered at top
- Card headings are bold sans-serif with category labels in parentheses
- Body text is regular weight with generous line-height for readability
- Numbered badges use bold white text

## Spacing System

**Base Unit:** 8px
**Scale:** 8, 16, 24, 32, 40, 48, 64, 80

**Common Patterns:**
- Card padding: 24-32px all sides
- Card margin bottom: 16-20px
- Badge size: 40px diameter
- Badge margin right: 16px
- Page padding: 40-48px sides, 64px top/bottom
- Heading margin bottom: 48px

## Component Styles

### Numbered List Cards
- Background: #F5F3EF
- Border radius: 12-16px
- Padding: 24px 32px
- Box shadow: 0 2px 8px rgba(0, 0, 0, 0.1)
- Display: Flex with badge and content
- Gap between cards: 16-20px

### Number Badges
- Size: 40px × 40px circle
- Background: #2D5547
- Text: White, 18-20px, 700 weight
- Alignment: Centered, flex-shrink: 0
- Position: Top-aligned with heading

### Content Container
- Max width: 800px
- Centered on page
- Responsive padding on mobile

## Layout Principles

- Max content width: 800px centered
- Vertical stacking with consistent gaps
- Cards span full width within container
- Badge + text flexbox layout within cards
- Responsive: Single column on all screen sizes
- Alignment: Heading centered, cards left-aligned content

## Visual Effects

- **Border Radius:** 12-16px on cards, 50% on badges
- **Shadows:** Subtle 0 2px 8px rgba(0,0,0,0.1) on cards
- **Gradients:** Vertical gradient on background (lighter top to darker bottom)
- **Backgrounds:** Solid cream for cards, gradient for page
- **Typography:** Serif for emphasis, sans-serif for readability

## Design Tone

This system projects sophistication and intentionality through its rich forest green palette and structured numbered framework. The warm cream cards against the deep green gradient create a premium, grounded aesthetic suitable for personal manifestos, principle frameworks, or mission statements. The generous spacing and clear hierarchy emphasize thoughtful reflection and strategic thinking.

## Usage Notes for AI Implementation

When implementing this system:
- Use the gradient background as the page foundation
- Maintain the numbered badge pattern for sequential content
- Keep card backgrounds consistent (cream) for content hierarchy
- Use serif fonts sparingly for main headings only
- Ensure generous padding within cards for readability
- Consider the numbered structure for any framework/principle-based content
- Mobile: Reduce outer padding but maintain card internal spacing
- The green palette works well for growth, sustainability, or personal development themes
