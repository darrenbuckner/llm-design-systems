# Serene Elegance

Elegant serif typography paired with dreamy, painterly aesthetics. Creating premium yet approachable experiences through refined execution and serene sophistication with a touch of whimsy.

**Primary Colors:**
- Primary Purple: #7B3FF2 — Used for primary CTAs, interactive elements, and brand accent moments
- Deep Black: #1A1A1A — Primary heading text, high-emphasis content

**Neutral Colors:**
- Surface White: #FFFFFF — Primary background for cards and input fields
- Body Text: #2D2D2D — Body copy and supporting text
- Placeholder Gray: #9B9B9B — Input placeholder text, subtle secondary information
- Soft Gray Background: #F5F7FA — Page background (very light, almost white with subtle cool tint)

**Natural/Illustrative Palette:**
- Vibrant Purple (florals): #9B5FCF — Decorative, illustration accent

- Sky Blue: #B8D8E8 — Illustration water, atmospheric elements
- Deep Green: #4A7C3B — Illustration shadows, depth in foliage

## Typography

**Font Families:**
- Display/Heading: High-contrast serif with elegant proportions, similar to Playfair Display or Bodoni
- Accent/Subheading: Italic serif for emphasis
- Body: Clean geometric sans-serif, similar to Inter, SF Pro, or Avenir
- UI Elements: Same geometric sans-serif for consistency

**Type Scale:**
- Display Heading (Brand Assets): 72px, Regular (400), 1.1 line-height
- Subheading Italic (made effortless): 64px, Italic (400), 1.1 line-height
- Body Large: 24px, Regular (400), 1.5 line-height
- Input Text: 18px, Regular (400), 1.4 line-height
- Placeholder: 18px, Regular (400), 1.4 line-height

**Hierarchy Rules:**
- Large serif headings create elegance and authority
- Italic serif adds playful sophistication to key phrases
- Sans-serif body text maintains readability and modern clarity
- High contrast between display type and body creates clear visual hierarchy

## Design Tone

This system exudes serene sophistication with a touch of whimsy. The elegant serif typography paired with dreamy, painterly illustrations creates a premium yet approachable feel. The design balances professional authority (clean sans-serif body text, generous whitespace) with creative warmth (illustrated natural scenes, playful italic accents, soft rounded corners). It suggests effortless ease and natural flow through both visual metaphor and refined execution.

## Usage Notes for AI Implementation

- The purple accent color should be used sparingly—primarily for primary actions and key interactive elements. Overuse diminishes its impact.
- Maintain extreme generosity in whitespace. Empty space is a feature, not a bug—it creates the "effortless" feeling the brand promises.
- Typography contrast is critical: large serif displays command attention, while clean sans-serif maintains usability. Never reverse these roles.
- Background illustrations should feel atmospheric and non-intrusive—they set mood without competing with content. Ensure adequate contrast between illustrated backgrounds and interactive UI elements.
- Border radius values are deliberately large (24px) to create soft, friendly, approachable interactions. Smaller radius values would make the system feel more corporate.
- The color palette outside of purple and neutrals comes from the illustration layer—don't use these greens/blues in UI components, keep them environmental.
