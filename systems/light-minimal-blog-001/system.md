# Parchment Editorial System

A clean, minimal editorial design system emphasizing readability and subtle warmth with careful typography hierarchy and muted accent colors.

## Color Palette

Primary Colors:
- Surface: #FFFFFF — Main background and content areas
- Secondary Surface: #F5F5F5 — Subtle section backgrounds

Neutral Colors:
- Background Primary: #FFFFFF
- Background Secondary: #F5F5F5 — Light gray for subtle contrast
- Text Primary: #333333 — Main headings and body text
- Text Secondary: #666666 — Subdued text and metadata
- Text Tertiary: #999999 — Captions and less important text
- Border Light: #E5E5E5 — Subtle dividers and borders

Accent Colors:
- Primary Accent: #8B5CF6 — Purple for CTAs and highlights
- Warm Accent: #E8D5C4 — Muted peach for featured content backgrounds
- Hover State: #7C3AED — Darker purple for interactive states

Brand Colors:
- Warm Orange: #D97706 — Secondary brand accent (icon elements)

## Typography

Font Families:
- Primary: System fonts (likely -apple-system, BlinkMacSystemFont, "Segoe UI")
- Display/Headings: Same as primary for consistency

Type Scale:
- Display: 32px, 600 weight, 1.2 line-height — Main headlines
- Heading 1: 28px, 600 weight, 1.3 line-height — Article titles
- Heading 2: 24px, 600 weight, 1.4 line-height — Section headers
- Heading 3: 20px, 600 weight, 1.4 line-height — Subsections
- Body Large: 18px, 400 weight, 1.6 line-height — Main content
- Body: 16px, 400 weight, 1.5 line-height — Standard text
- Small: 14px, 400 weight, 1.4 line-height — Metadata, captions
- Tiny: 12px, 400 weight, 1.3 line-height — Fine print

Hierarchy Rules:
- Headlines use semibold weight (600) for emphasis
- Body text maintains regular weight (400) for readability
- Generous line-height for comfortable reading
- Clear size jumps between hierarchy levels

## Spacing System

Base Unit: 4px
Scale: 4, 8, 12, 16, 20, 24, 32, 48, 64, 96px

Common Patterns:
- Component padding: 16-24px standard, 32-48px for major sections
- Vertical rhythm: 24px between paragraphs, 32-48px between sections
- Container margins: 16-24px on mobile, 32-48px on desktop
- Button padding: 12px vertical, 20px horizontal

## Component Styles

### Buttons
Primary Button:
- Background: #8B5CF6
- Text: #FFFFFF
- Padding: 12px 20px
- Border radius: 6px
- Font weight: 500
- Hover: #7C3AED background
- Focus: 2px outline, 2px offset

Ghost/Text Button:
- Background: transparent
- Text: #8B5CF6
- Padding: 8px 12px
- Hover: light purple background tint

### Cards/Content Blocks
Featured Content Block:
- Background: #E8D5C4 (warm peach)
- Padding: 32px
- Border radius: 8px
- No border or shadow
- Generous internal spacing

### Input Fields
- Border: 1px solid #E5E5E5
- Padding: 12px 16px
- Border radius: 6px
- Focus: #8B5CF6 border color
- Background: #FFFFFF

### Navigation
- Clean, minimal navigation bar
- Text links with no underlines
- Hover states with color change to accent purple
- Icon + text combinations for actions

## Layout Principles

- Max content width: ~800px for optimal reading
- Generous whitespace and padding throughout
- Single-column layout prioritizing readability
- Centered content alignment
- Responsive behavior with consistent margins

## Visual Effects

- Border Radius: 6-8px for buttons and inputs, larger for content blocks
- Shadows: Minimal or none — relies on background color contrast
- Borders: 1px thickness, light gray (#E5E5E5)
- Backgrounds: Solid colors, no gradients or patterns

## Design Tone

Clean, minimal, and editorial-focused with an emphasis on readability and content hierarchy. The warm neutral palette creates an approachable, comfortable reading experience while maintaining professional presentation.

## Usage Notes for AI Implementation

This system prioritizes content readability above all else. Use generous whitespace, maintain consistent vertical rhythm, and ensure high contrast ratios for text. The purple accent should be used sparingly for key interactive elements and highlights.
